# World in 3 — daily news data

Daily world-news summaries for Korean learners of English and French, used by the World in 3 app.

- `index.json` — list of published days (newest first)
- `days/YYYY-MM-DD.json` — the stories for one day

Each story is written in our own words from facts reported by the linked sources, with AI assistance and human review.
Some stories draw on Wikipedia's Current events portal.
